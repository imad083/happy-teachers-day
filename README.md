# A Letter of Appreciation — Happy Teachers' Day

Static site (HTML/CSS/vanilla JS). No build step, no data collection.

## Edit before publishing
- `index.html`: replace `[Your name]` and the marked personal paragraph in the letter.
- Music (optional): put an MP3 you have rights to in `assets/music/`, then set `MUSIC_FILE` in `js/script.js`.

## Deploy to GitHub Pages
1. Push this folder to a GitHub repository.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / root.
3. Open the URL GitHub shows (https://<username>.github.io/<repo>/).
